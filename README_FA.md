# سنگارا — نسخه ۱٫۱ (سورس وب + پیش‌نمایش HTML موبایل)

## 📱 دیدن سایت روی گوشی — بدون نصب و بدون اینترنت

فایل **Sangara_Mobile_Preview.html** را به گوشی منتقل کنید و از بخش Files / فایل‌های من، آن را با مرورگر باز کنید.
این یک فایل مستقل است؛ تصاویر، طراحی و عملکردهای نمایشی آن در همان فایل قرار دارند.
برای این پیش‌نمایش **نیازی به Node.js، نصب برنامه، سرور، اینترنت یا فایل کناری نیست**.

امکانات پیش‌نمایش: نمایش واکنش‌گرا، جست‌وجو، فیلتر دسته‌ها، مرتب‌سازی، علاقه‌مندی، جزئیات محصولات، سبد خرید با افزایش/کاهش تعداد، کپی فهرست انتخاب‌ها، راهنمای محصول و منوی پایین موبایل. در مرورگرهایی که ذخیره‌سازی محلی را مجاز بدانند، سبد خرید و علاقه‌مندی‌ها باقی می‌مانند.

**مهم:** این فایل HTML فقط نسخه آفلاین آزمایشی است؛ سفارش واقعی، پرداخت، موجودی و حساب کاربری متصل به سرور ندارد. قیمت‌ها و اطلاعات محصولات صرفاً نمونه هستند.

## 💻 اجرای سورس وب اصلی روی ویندوز

۱. تمام پوشه `Sangara_Install_Run` را از ZIP استخراج کنید (Extract All).
۲. `INSTALL_RUN.bat` را اجرا کنید.
۳. اولین اجرا به اینترنت نیاز دارد. در نبود Node.js ۲۲٫۱۳ یا بالاتر، نصب‌کننده Node.js قابل‌حمل را از منبع رسمی دریافت و بررسی صحت می‌کند، سپس بسته‌های npm را دانلود می‌کند.
۴. مرورگر به نشانی محلی `http://127.0.0.1:3000` یا در صورت اشغال پورت به نشانی دیگری از بازه ۳۰۰۰ تا ۳۰۱۹ باز می‌شود. تا زمانی که از سایت استفاده می‌کنید، پنجره اجرا را باز نگه دارید.

ویندوز ۱۰ یا ۱۱ و PowerShell 5.1+ پیش‌نیاز هستند. برای توقف از Ctrl+C استفاده کنید؛ خطاها در `install-run.log` ثبت می‌شوند. اولین نصب به دسترسی به nodejs.org و registry.npmjs.org وابسته است.

## تغییرات نسخه ۱٫۱

- اصلاح نمایش تصویر محصول؛ تصویر مستقل و بهینه برای هر یک از شش محصول نمایشی.
- تصویر جداگانه برای هر کارت دسته‌بندی به‌جای تکرار یک تصویر.
- ناوبری ثابت پایین موبایل شامل خانه، محصولات، علاقه‌مندی و سبد خرید.
- سازگاری بهتر با صفحه‌های کوچک، ناوبری دسته‌بندی و نمایش جزئیات.
- قابلیت کپی فهرست محصولات سبد و خالی کردن سبد.
- فایل HTML آفلاین مستقل، با طراحی و امکانات نمایشی هم‌راستا با فروشگاه اصلی.
- داده محصولات مشترک در `data/products.json`؛ فایل HTML با `python scripts/build-mobile-preview.py` دوباره تولید می‌شود (بدون نیاز به کتابخانه ثالث).
- تصاویر منسوخ حذف شده‌اند تا بسته سبک‌تر شود. از فونت‌های موجود روی دستگاه استفاده می‌شود.

## حدود و تست

فایل HTML در مرورگر Chromium در اندازه‌های ۳۲۰، ۳۹۰ و ۱۳۶۶ پیکسل با موفقیت بررسی شد (همچنین کلیک‌ها و سبد خرید). سورس TSX از نظر نحوی بررسی شد؛ اما اجرای واقعی Next.js و فایل BAT در محیط ساخت این بسته ممکن نبود، چون کتابخانه‌های npm در دسترس نبودند. هیچ ادعای تست نصب روی ویندوز یا پرداخت واقعی وجود ندارد.
